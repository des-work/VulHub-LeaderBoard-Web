## 📚 Documentation Philosophy

The new structure follows these principles:

### 1. Progressive Disclosure
- **Start simple** - Quick start guide (5 min)
- **Go deeper** - Local development guide (full details)
- **Explore advanced** - Architecture, deployment, etc.

### 2. Role-Based Navigation
- Different roles need different information
- Master index provides multiple entry points
- Quick links for common tasks

### 3. Task-Oriented Organization
- Organized by what you want to do
- Not by file type or date created
- Deployment/, development/, operations/, etc.

### 4. Historical Preservation
- Don't delete history
- Archive in project-history/
- Available for reference but not cluttering

### 5. Single Source of Truth
- One place for each topic
- No duplicate content
- Clear ownership
